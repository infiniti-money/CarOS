# Infiniti CarOS 2.0

Vietnamese Edition — ứng dụng dashboard ô tô độc lập cho iPhone, iPad và Android. Thiết kế lấy cảm hứng từ CarOS và Liquid Glass, không liên kết với Apple hoặc CarOS.

Giai đoạn đầu: dashboard, SmartBar, giao diện thích ứng, mở ứng dụng bản đồ/âm nhạc và tùy chọn ngày đêm. Các tích hợp native và dữ liệu GPS sẽ được triển khai riêng; không giả lập dữ liệu xe.
