# OBD-II BLE (experimental, read only)
CarOS supports a deliberately limited ELM327-compatible BLE UART adapter advertising FFE0, using FFE1 notifications and acknowledged writes. Other profiles (Nordic UART, proprietary BLE, Wi-Fi, Bluetooth Classic SPP) are not supported. Connect only to your own adapter while parked. Android 12+ requests nearby-device scan/connect permission; older Android uses location permission for BLE. iOS uses CoreBluetooth consent. Scan is bounded, only matching advertised service shown; user explicitly confirms. Auto reconnect is opt-in, saved local device ID only, at most 3 retries while screen is active; manual disconnect disables it. No background scan, no telemetry storage/upload, no VIN or DTC reads. Adapter AT setup commands configure only formatting/protocol selection; fixed Mode 01 read commands for RPM, ECU speed, coolant temperature, fuel level and module voltage. No raw command UI, ECU writes, clearing DTC or security access. Missing/conflicting/unrecognized readings show unavailable; stale values hidden after 12s, clear on disconnect. Physical adapter/ECU compatibility, permissions, write/notify profile and reliability require real parked vehicle tests. No substitute for certified vehicle instruments.
Sources: https://pub.dev/packages/flutter_reactive_ble/versions/5.4.2 ; https://pub.dev/packages/permission_handler ; SAE J1979 Mode 01.
