# Infiniti dashboard — Vietnamese native glass
Dashboard inspired by automotive app launchers, original icons and layout, responsive columns. Flutter Material localization vi, native iOS bundle locale vi. Native SmartBar is a SwiftUI platform view using Apple GlassEffectContainer and .buttonStyle(.glass) on iOS 26+ (including iOS 27 if supported); requires an SDK exposing these APIs. All other panels remain Flutter-rendered, not native Liquid Glass. Older iOS/Android or disabled glass use Flutter fallback. System speech locale and third-party service language remain platform-dependent. 
Build generates AppDelegate then scripts/configure_location.py ios injects bridge from native/ios/GlassBar.swift. Test native rendering, action dispatch, contrast, orientation and iPad on actual devices; widget test covers fallback only. No CarOS proprietary assets copied. https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views ; https://docs.flutter.dev/platform-integration/ios/platform-views

## Native launcher extension
SwiftUI GlassEffectContainer now also renders the dashboard app launcher with original SF Symbols and interactive circular glass. Wide layouts (>=900 logical pixels) separate trip and launcher into two columns. Flutter fallback keeps all actions when glass is disabled or native unavailable. Native controls are still a subset, not a full SwiftUI rewrite: trip, map, media and communication screens remain Flutter. Visual QA and exact Vietnamese localization on-device pending.
